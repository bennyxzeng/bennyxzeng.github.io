Loremark

A spoiler-free reading companion for Android and iOS

Loremark helps readers keep track of long, complex books. It writes recaps, answers questions, and maps how characters relate, using only the chapters the reader has finished.

  • Led the team that built one Flutter app for both platforms, now in beta with EPUB reading, notes and highlights, search, a Story Map, and an AI chat
  • Built an on-device AI pipeline that grows each book’s story model chapter by chapter and checks every model response against a schema, so spoilers and corrupted data never reach the reader
  • Added note-taking and highlighting on the Readium EPUB engine, and tuned text processing to handle very long books quickly
  • Runs with no backend: the app calls OpenAI or DeepSeek directly with the reader’s own key, kept in the phone’s secure storage
  • Flutter
  • Dart
  • Readium
  • OpenAI API
  • DeepSeek API

Memoize

A flashcard app for Android and iOS

A mobile app for making, organizing, and practicing flashcard decks, built with one teammate.

  • Switches the whole interface between English, Spanish, and Chinese while the app is running
  • Stores decks, cards, and definitions on the device in a Drift (SQLite) database
  • Suggests definitions from a dictionary API so new cards take less typing
  • Practice mode uses gestures: swipe between cards, long-press for a hint, double-tap to skip, shake to shuffle
  • Includes light and dark themes, undo for deletions, and screen-reader labels throughout
  • Flutter
  • Dart
  • Drift
